# Baby Tracker reconstruction

Build an independent Flutter reconstruction of Baby Tracker / Luli 2.9.0 from the reviewed evidence at `/home/quantavil/Documents/baby-tracker-clone/evidence/original-analysis`. The user explicitly requested building now after agreeing to build the verified core and validate features incrementally. Implement inline; avoid additional design approval cycles given that instruction.

## First deliverable
Home, History, Stats premium promotion, Settings, the eight-category activity menu, free wake-up/nap/bedtime/night-waking editors, editing/deleting local logs, ongoing sleep pause/resume/stop, profile/regional/sleep preferences, circle explanation and share preview. Use original packaged fonts/artwork. Keep the original package/session untouched; Android application ID is `dev.quantavil.babytracker`.

Use immutable domain models, one ChangeNotifier controller and an injected JSON storage repository, with shared_preferences for mobile/web persistence. Separate feature widgets; no code generation, dependency injection framework, backend, subscriptions or caching layer. Start with an empty local profile and records, offering optional clearly labeled demo records. Never import original private account data.

Dark violet surfaces, lavender accents, SourceSerif4 headings and RobotoFlex body; render the circular schedule from actual local logs. Captured predictions cannot be reconstructed reliably: show collecting-data state without fabricated schedules or overslept calculations. Premium rows open a dismissible preview with unavailable purchase explained on action; no invented price/entitlement. Notifications setting is saved but notification delivery is not implemented. Share preview supports copying a text summary; native image export is deferred.

Editors store local date/time, note and optional interval end. Reject reversed/zero intervals, dates in the future and wake-up outside observed 03:00–15:00 window; the inclusive endpoints are a provisional local rule. One active sleep interval at a time. Pause excludes paused duration from totals; persist pause state across relaunch. Overlapping naps count their unpaused union; edited pauses move with start-time corrections and clip at end. Day totals intersect each interval with the selected local calendar day (including midnight crossings); bedtimes themselves do not count as intervals. Updates persist before publishing UI state, and a storage failure leaves the previous state intact. Corrupt saved data displays recovery guidance without silently overwriting it.
